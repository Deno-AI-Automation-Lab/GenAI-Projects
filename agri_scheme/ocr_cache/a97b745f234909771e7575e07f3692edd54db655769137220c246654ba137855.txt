TAMIL TEXT:

அரசாணை (நிலை) எண். 298, வணிகமைப்பு முறைநடை (வியுதி) துறை, நாள் 16.12.2022.

| 6. | கூட்டுறவு இணைபதிவாளர் | உறுப்பினர் |
| 7. | இணை இயக்குநர் (காஞ்சனை பராமரிப்புத்துறை) | உறுப்பினர் |
| 8. | செயற்பொறியாளர் (நீர்வழி ஆதாரத்துறை) | உறுப்பினர் |
| 9. | மாவட்ட ஆட்சியர் நேர்முக உதவியாளர் (வணிகமைப்பு) | ஒருங்கிணைப்பாளர் |
| 10. | தோட்டக்கலை துணை இயக்குநர் | உறுப்பினர் |
| 11. | வணிகமைப்பு துணை இயக்குநர் (வணிக வாணிகம்) | உறுப்பினர் |
| 12. | மாவட்ட செயற்பொறியாளர் (வணிகமைப்பு பொறியியல் துறை) | உறுப்பினர் |
| 13. | செயற்பொறியாளர் (Groundwater)-(பொதுப்பணித்துறை) | உறுப்பினர் |
| 14. | மாவட்ட முன்னோடி வங்கி மேலாளர் | உறுப்பினர் |
| 15. | மாவட்ட மின்வாரிய கண்காணிப்பு பொறியாளர் | உறுப்பினர் |
| 16. | மண்டல வணிகர்-நுகர்பொருள் வாணிகக் கழகம் | உறுப்பினர் |
| 17. | தமிழ்நாடு வணிகமைப்பு பல்கலைக்கழகம் / மாவட்ட கே.வி.ஐ.சி. கிஞ்சுக்களங்கள் | உறுப்பினர் |
