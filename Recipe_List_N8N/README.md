# 🛒 Slack Recipe Shopping List (n8n + OpenAI)

An **n8n** workflow that turns a Slack channel into a shopping-list assistant. Post a dish name, such as
*"Paneer Butter Masala"* or *"I need to cook Tandoori Chicken"*, and the bot replies in the same
channel with a **bulleted list of ingredients and approximate quantities**, generated by OpenAI
`gpt-4.1-mini`.

## Workflow

```
Slack Trigger (new message) ─► If (not from a bot) ─► Edit Fields (recipe = message text)
        ─► Basic LLM Chain  ◄── OpenAI Chat Model (gpt-4.1-mini)
        ─► Slack: Send a message (same channel)
```

| Node | Type | What it does |
|---|---|---|
| Slack Trigger | Slack Trigger | Fires on every new message in the configured channel |
| If | If | Continues only when `bot_id` is empty, so the bot ignores its own replies and doesn't loop |
| Add Recipe | Edit Fields (Set) | Copies the message text into a `recipe` field |
| Basic LLM Chain | LangChain LLM Chain | Checks the request and builds the ingredient list |
| OpenAI Chat Model | OpenAI | `gpt-4.1-mini`, used by the chain |
| Send a message | Slack | Posts the result back to the channel |

## How the AI responds

The prompt tells the model to:

- Accept a bare dish name **or** a sentence, as long as the dish is clear
- **Not guess**: for empty, unclear, unrelated or ambiguous misspelt input (e.g. *"check biryani"*), it replies only
  `Please enter a clear recipe name and try again.`
- Return a short **bulleted list with approximate quantities**
- Leave out cooking steps unless asked

### Example

**You:** `Paneer Butter Masala`

**Bot:**
```
• Paneer – 250 g
• Butter – 2 tbsp
• Tomatoes – 4 medium
• Onion – 1 large
• Cashews – 10–12
• Fresh cream – ¼ cup
• Ginger-garlic paste – 1 tbsp
• Kashmiri chilli powder, garam masala, kasuri methi, salt – to taste
```

(The actual output varies.)

## Requirements

- **n8n** reachable at a **public HTTPS URL** (Slack sends events to the trigger's webhook)
- A **Slack app** installed in your workspace
- An **OpenAI API key**

See `requirements.txt` for the full list. There are no Python packages to install.

## Setup

### 1. Create the Slack app

1. Go to **api.slack.com/apps → Create New App → From scratch**.
2. **OAuth & Permissions → Bot Token Scopes:** add `channels:history` and `chat:write`
   (use `groups:history` for a private channel).
3. **Install to Workspace** and copy the **Bot User OAuth Token** (`xoxb-…`).
4. In Slack, invite the bot to your channel: `/invite @YourAppName`.

### 2. Import the workflow into n8n

**Workflows → Import from File → `Slack Recipe Shopping List.json`**

### 3. Connect credentials

The credential IDs in the JSON belong to the original instance, so reconnect them:

- **Slack Trigger** and **Send a message**: create a **Slack API** credential with the `xoxb-` token
- **OpenAI Chat Model**: create an **OpenAI** credential with your API key

### 4. Set your channel

Replace the channel ID in **both** Slack nodes with your own. To find it, open the channel in Slack and
choose **View channel details**; the ID (`C0…`) is at the bottom.

### 5. Connect Slack events to n8n

1. Open **Slack Trigger** and copy its **Production URL**.
2. In the Slack app, go to **Event Subscriptions → Enable Events**, paste the URL and wait for **Verified**.
3. Under **Subscribe to bot events**, add `message.channels` (or `message.groups` for private channels), then save and reinstall the app if prompted.

### 6. Activate

Toggle the workflow **Active** and post a dish name in the channel.

## ⚠️ Things to know

| Point | Detail |
|---|---|
| Public URL needed | `localhost` won't work for the trigger. Use n8n Cloud, a server with a domain, or a tunnel (`n8n start --tunnel`, ngrok, Cloudflare Tunnel) |
| Loop protection | The **If** node ignores bot messages; keep it, or the bot will reply to itself forever |
| Every message triggers it | Any human message in the channel (including "thanks!") gets a reply, so use a dedicated channel |
| Replies go to the channel | Not into a thread. To reply in a thread, set **Thread TS** in "Send a message" to the trigger's `ts` |
| Costs | Each message makes one OpenAI call |
